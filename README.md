# NEXUS-PC — выпуски

Здесь публикуются установщики NEXUS-PC — оптимизатора Windows 10/11 для игр.

- Скачать: раздел **Releases** → `NEXUS-PC-Setup.exe`.
- `SHA256SUMS.txt` — контрольные суммы. Программа сверяет с ними скачанный установщик и без совпадения ничего не ставит.
- Обновление из программы: «Настройки» → «Обновления» → «Проверить обновления».

Файл не подписан сертификатом: Windows может показать «неизвестный издатель» («Подробнее» → «Выполнить в любом случае»).
